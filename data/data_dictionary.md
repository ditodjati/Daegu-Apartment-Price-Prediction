## 📅 Data Description

| Column Name               | Description                                                                     |
| ------------------------- | ------------------------------------------------------------------------------- |
| ID                        | Unique identifier for each transaction                                          |
| city                      | City name (e.g., Daegu Metropolitan City)                                       |
| county_or_gu              | District ("gu") or county ("gun") name                                          |
| sub_locality              | Sub-local administrative unit (e.g., neighborhood "dong", "eup", "myeon", "ri") |
| address_number            | Lot number (beonji)                                                             |
| main_number               | Main lot number                                                                 |
| sub_number                | Sub lot number                                                                  |
| road_name                 | Road name address                                                               |
| building_name             | Name of the apartment complex or building                                       |
| building_block            | Building block or unit designation                                              |
| floor                     | Floor number                                                                    |
| exclusive_area_m2         | Exclusive residential area in square meters                                     |
| total_area_m2             | Total floor area in square meters                                               |
| land_area_m2              | Land area in square meters                                                      |
| land_ownership_area_m2    | Land ownership area in square meters                                            |
| construction_year         | Year the building was constructed                                               |
| contract_year_month       | Contract year and month (YYYYMM)                                                |
| contract_day              | Contract day (DD)                                                               |
| housing_type              | Housing type (e.g., apartment, officetel, etc.)                                 |
| transaction_type          | Type of transaction (intermediary or direct)                                    |
| transaction_price_krw_10k | Transaction price in units of 10,000 KRW (integer)                              |
